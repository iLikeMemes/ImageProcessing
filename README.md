# ImageProcessing
A collection of image processing assignments. Including the final assignment which is to detect any object using classic image processing techniques, which in this case is analog clocks.

There are some example images which can be used as input for the image recognition. Some images will lead to incorrect detection, but this is intentional, as to show the flaws of the implementation.
Do note that the detection implementation is a bit computationally expensive, so larger images can take extreme amounts of time.

There are no images to test the assignments, but you can easily create some in paint, or download some.

# Running this
This is a winforms project. Use your preferred method to compile and run the solution. Example: download this repo into visual studio and compile + run
